02 · Concepto

¿Qué es el lenguaje ensamblador?

Es un lenguaje de bajo nivel que utiliza nombres simbólicos (mnemónicos) para representar instrucciones de una arquitectura de procesador.

Lenguaje máquina

10111000 00000101 00000000

Representación binaria de una instrucción en una codificación x86 concreta.

Ensamblador

MOV AX, 5

Una forma legible para humanos de cargar el valor 5 en AX.

El ensamblador depende de la arquitectura: x86, ARM y RISC-V usan conjuntos de instrucciones diferentes.

05 · Registros

Registros generales en nuestro modelo

RegistroUso didáctico
AXAcumulador / resultado
BXSegundo operando
CXContador de ciclos
DXDato auxiliar

Ejemplo

MOV AX, 10 MOV BX, 4 ADD AX, BX

Al terminar: AX = 14, BX = 4.

En el simulador, AX/BX/CX/DX son enteros con signo de 16 bits. En x86 real, sus interpretaciones y banderas dependen de la operación.
06 · Estructura

Anatomía de una instrucción

inicio: MOV AX, 8 ; cargar el número 8 ADD AX, 2 ; sumar 2 HLT ; detener

Etiqueta

inicio: identifica una posición del programa.

Mnemónico

MOV, ADD, HLT indican operaciones.

Operandos

AX, 8 especifica destino y origen.

El texto tras ; es un comentario. Las etiquetas no son instrucciones ejecutables.

07 · Datos

Valores inmediatos y registros

MOV AX, 12 MOV BX, AX MOV CX, -3

Inmediato: número escrito en la instrucción. Registro: valor guardado en AX, BX, CX o DX.

Estado final

AX = 12BX = 12CX = -3

MOV copia un valor: no borra el registro de origen.

09 · Comparaciones

CMP y las banderas de estado

MOV AX, 7 CMP AX, 7 JE iguales MOV BX, 0 JMP fin iguales: MOV BX, 1 fin: HLT

¿Qué hace CMP?

Compara como si restara los operandos, pero no modifica AX.

ZF = 1 cuando son iguales; SF indica el signo del resultado de comparación.

En este ejemplo BX = 1.

Para saltos con signo, el simulador evalúa la comparación guardada; en x86 real se combinan banderas como ZF, SF y OF.

10 · Flujo de control

Saltos condicionales e incondicionales

SaltoSignificado
JMP etiquetaSalta siempre
JE / JNEIgual / diferente
JG / JLMayor / menor (con signo)
JGE / JLEMayor o igual / menor o igual
Un salto cambia la próxima instrucción que se ejecutará. Una etiqueta señala el destino.
11 · Ejemplo resuelto

Determinar el mayor de dos números

MOV AX, 15 MOV BX, 9 CMP AX, BX JG mayor MOV DX, BX JMP fin mayor: MOV DX, AX fin: PRINT DX HLT

Traza de ejecución

1. AX recibe 15; BX recibe 9.

2. CMP compara 15 con 9.

3. JG se cumple: se salta a mayor.

4. DX recibe 15; PRINT muestra 15.

12 · Repetición

Construir un ciclo con etiquetas

MOV CX, 1 ciclo: PRINT CX INC CX CMP CX, 6 JL ciclo HLT

¿Qué muestra?

1, 2, 3, 4, 5

La comparación ocurre después de incrementar CX. Mientras CX sea menor que 6, se repite el ciclo.

Evita los ciclos infinitos: cada repetición debe acercarse a una condición de salida.

14 · Modelo de programa

Dos formas de escribir ASM

Programa didáctico del simulador

MOV AX, 5 MOV BX, 3 ADD AX, BX PRINT AX HLT

PRINT y HLT son comandos del simulador; PRINT no es una instrucción x86 nativa.

Programa real: depende del entorno

Un programa para NASM/x86-64 en Linux requiere directivas, punto de entrada, convenciones del sistema y llamadas al sistema para mostrar resultados.

El laboratorio permite centrarse primero en la lógica de las instrucciones.

21 · Errores frecuentes

Depuración: ¿qué podría fallar?

Registro desconocido

MOV EX, 5

EX no existe en nuestro modelo.

Etiqueta inexistente

JMP salida

Debe existir salida:.

Ciclo sin fin

inicio: JMP inicio

Se alcanza el límite de pasos.

Estrategia: identifica el error, formula una hipótesis, corrige una instrucción y ejecuta paso a paso.
